Ngoding PAWN langsung dari HP

PawnStudio adalah IDE mobile untuk scripting PAWN / SA-MP. Tulis, edit, dan compile gamemode tanpa laptop.

Download APK GitHub

Fitur

Editor PAWN

Edit file .pwn dan .inc langsung di Android.

Compile

Compile gamemode jadi .amx dari dalam aplikasi.

Ringan

Dibuat untuk dipakai di HP, tanpa setup ribet.

Panduan Singkat

  1. Download APK terbaru dari halaman Releases.
  2. Install APK (izinkan install dari sumber tidak dikenal).
  3. Buka PawnStudio, pilih folder gamemode lo.
  4. Edit file .pwn, lalu tekan Compile.

Contoh struktur folder:

gamemodes/
  nama.pwn
  nama.amx
pawno/include/
  a_samp.inc

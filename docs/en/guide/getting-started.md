# Quick Start

## Install

1. Open the [Releases](https://github.com/Julakk/Pawn-Studio/releases/latest) page.
2. Download the latest APK file.
3. Install the APK (allow installs from unknown sources if asked).
4. Open PawnStudio and grant storage access.

## Open your first project

1. Pick the folder that contains your gamemode.
2. Open the `.pwn` file you want to edit.
3. Tap the Compile button to produce an `.amx` file.

Continue to [How to Use](/en/guide/usage).

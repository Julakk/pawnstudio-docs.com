# Extension Catalog

PawnStudio has an **Extensions Panel** (puzzle icon in the activity bar) for installing snippets, editor themes, and include packs in JSON format. Extensions only contain data and don't run code, so they're safe to install.

## How to Install

1. Open the **Extensions Panel** (puzzle icon in the activity bar).
2. Install from a file, or from a GitHub repo that contains a `pawnstudio-extension.json` file.
3. Enable, disable, or remove it at any time. Use the **Search extensions** field to filter the list.

## Submit Your Extension

1. Create a GitHub repo containing a `pawnstudio-extension.json` file.
2. Try installing from that repo in PawnStudio until it works.
3. Send it via a [GitHub Issue](https://github.com/Julakk/pawnstudio-docs.com/issues/new?title=Extension%3A%20&body=Extension%20name%3A%0AType%20(snippet%20%2F%20theme%20%2F%20include%20pack)%3A%0AGitHub%20repo%3A%0AShort%20description%3A%0A) or on [Discord](https://discord.gg/82hxdZy6Gf).
4. After review, your extension is added to this catalog.

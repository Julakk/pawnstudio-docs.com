# Versi SA-MP & open.mp

PawnStudio punya pilihan versi SA-MP dan dukungan include open.mp.

## Versi yang tersedia

| Versi | Catatan |
| --- | --- |
| 0.3.DL-R1 | Versi 0.3.DL, untuk server yang pakai fitur custom model |
| 0.3.7-R2-1 | Versi 0.3.7 revisi R2-1 |
| 0.3.7-R3 | Versi 0.3.7 revisi R3 |

## Cara memilih

Samakan dengan versi server yang lo pakai. Kalau versinya beda, bisa muncul error karena native function atau include yang nggak cocok.

## open.mp

open.mp punya include sendiri. PawnStudio mendukung include open.mp, jadi lo bisa compile gamemode untuk server open.mp. Pastikan include open.mp ada di folder include proyek.

::: tip Catatan
Posisi menu pilihan versi bisa berbeda antar versi aplikasi. Biasanya ada di Pengaturan.
:::

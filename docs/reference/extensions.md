# Katalog Ekstensi

PawnStudio punya **Panel Ekstensi** (ikon puzzle di activity bar) untuk memasang snippet, tema editor, dan paket include dalam format JSON. Ekstensi hanya berisi data dan tidak menjalankan kode, jadi aman dipasang.

## Cara Pasang

1. Buka **Panel Ekstensi** (ikon puzzle di activity bar).
2. Pasang dari file, atau dari repo GitHub yang berisi file `pawnstudio-extension.json`.
3. Aktifkan, nonaktifkan, atau hapus kapan saja. Pakai kolom **Cari ekstensi** buat menyaring daftar.

## Kirim Ekstensi Lo

1. Bikin repo GitHub yang berisi file `pawnstudio-extension.json`.
2. Coba pasang dari repo itu di PawnStudio sampai jalan.
3. Kirim lewat [Issue di GitHub](https://github.com/Julakk/pawnstudio-docs.com/issues/new?title=Ekstensi%3A%20&body=Nama%20ekstensi%3A%0AJenis%20(snippet%20%2F%20tema%20%2F%20paket%20include)%3A%0ARepo%20GitHub%3A%0ADeskripsi%20singkat%3A%0A) atau lewat [Discord](https://discord.gg/82hxdZy6Gf).
4. Setelah dicek, ekstensi lo dimasukin ke katalog ini.
